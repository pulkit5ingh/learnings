**Type:** Assignment

## Goal
Stop debugging with `console.log` alone: pause running Node programs, inspect state, step through async code, and debug servers and tests.

## Background

### The V8 inspector
`node --inspect app.js` opens a debugging port (default `127.0.0.1:9229`) that speaks the Chrome DevTools Protocol. Chrome (`chrome://inspect`), VS Code, and WebStorm can attach to it.
- `--inspect` — run normally, accept a debugger anytime
- `--inspect-brk` — pause before the first line (for startup bugs)
- `--inspect-wait` — wait for a debugger to attach, then run
- `--inspect=0.0.0.0:9229` — listen on all interfaces. **Never do this on a public network**: the inspector gives full code execution.

### Breakpoint kinds
Line breakpoints, **conditional** breakpoints (pause only when `userId === 42`), **logpoints** (print without editing code), exception breakpoints (pause on caught/uncaught), and the `debugger;` statement in code.

### Async stack traces
V8 stitches stack traces across `await`, so you can see the call path that led to an async function — as long as you use `async`/`await` rather than raw callbacks.

### Better logging
- `console.dir(obj, { depth: null })` / `util.inspect(obj, { depth: null, colors: true })` — print nested objects fully.
- `console.table`, `console.time`/`timeEnd`, `console.trace` — tables, timing, stacks.
- `util.debuglog('mymodule')` — logs only when `NODE_DEBUG=mymodule` is set. Node's own modules support this too: `NODE_DEBUG=http,net node app.js`.

### Debugging tests
`node --inspect-brk --test test/foo.test.js` or VS Code's JavaScript Debug Terminal attaches to every process automatically, including test child processes.

## Tasks

### 1. A buggy program

```bash
mkdir a7-3-debug && cd a7-3-debug
npm init -y && npm pkg set type=module
```

```js
// buggy.js
const orders = [
  { id: 1, items: [{ price: 10, qty: 2 }, { price: 5, qty: 1 }], coupon: 'SAVE10' },
  { id: 2, items: [{ price: 20, qty: 1 }], coupon: null },
  { id: 3, items: [{ price: '15', qty: 2 }], coupon: 'SAVE10' },
];

const coupons = { SAVE10: 0.1 };

function orderTotal(order) {
  let total = 0;
  for (const item of order.items) total += item.price * item.qty;
  const discount = coupons[order.coupon] ?? 0;
  return total - total * discount;
}

async function fetchOrder(id) {
  await new Promise((r) => setTimeout(r, 10));
  return orders.find((o) => o.id === id);
}

async function report(ids) {
  let sum = 0;
  for (const id of ids) {
    const order = await fetchOrder(id);
    sum += orderTotal(order);
  }
  return sum;
}

console.log('grand total:', await report([1, 2, 3, 4]));
```

Run it: `node buggy.js`. It crashes on order 4, and order 3's string price is a hidden bug.

### 2. Debug in Chrome DevTools

```bash
node --inspect-brk buggy.js
```

Open `chrome://inspect` → **Open dedicated DevTools for Node**. Then:
1. Set a breakpoint inside `orderTotal` and resume (F8).
2. Inspect `order` and `item` in the Scope panel; hover over variables.
3. Add a **conditional breakpoint** on the `total +=` line: `typeof item.price !== 'number'`.
4. Enable **Pause on uncaught exceptions** and find order 4 in the async call stack.
5. Use the Console while paused: evaluate `order.items.map(i => i.price)`.

Fix both bugs: validate that `fetchOrder` found an order, and coerce/validate `price`.

### 4. Debug a running server

```js
// server.js
import { createServer } from 'node:http';

let requests = 0;
createServer((req, res) => {
  requests++;
  const user = { id: requests, name: req.headers['x-user'] ?? 'anon', roles: requests % 3 === 0 ? ['admin'] : ['user'] };
  if (user.roles.includes('admin')) debugger;     // pauses only when a debugger is attached
  res.end(JSON.stringify(user));
}).listen(3000);
```

```bash
node --inspect server.js
for i in 1 2 3; do curl -s localhost:3000 -H "x-user: ada"; echo; done
```

Attach Chrome or VS Code and watch the third request pause. Note that while paused, **all** requests hang — never leave a debugger paused on production.

You can also enable the inspector on a process that was started without it: `kill -USR1 <pid>` (Linux/macOS).

### 5. Better logging tools

```js
// logging.js
import util from 'node:util';

const nested = { a: { b: { c: { d: { e: 'deep' } } } }, list: Array.from({ length: 150 }, (_, i) => i) };
console.log(nested);                                         // truncated: [Object], ... 50 more items
console.dir(nested, { depth: null, maxArrayLength: 5 });
console.log(util.inspect(nested, { depth: 2, colors: true, compact: false }));

console.table([{ id: 1, ok: true }, { id: 2, ok: false }]);
console.time('work'); for (let i = 0; i < 1e6; i++); console.timeEnd('work');
console.trace('how did we get here?');

const debug = util.debuglog('orders');
debug('only printed when NODE_DEBUG includes "orders": %o', { id: 1 });
```

```bash
node logging.js
NODE_DEBUG=orders node logging.js
NODE_DEBUG=http node -e "require('http').get('http://example.com', (r) => r.resume())"   # Node's own internal http logs
```

### 6. Debug a failing test

```js
// math.test.js
import { test } from 'node:test';
import assert from 'node:assert/strict';

const average = (xs) => xs.reduce((a, b) => a + b) / xs.length;

test('average of empty list is 0', () => {
  assert.equal(average([]), 0);
});
```

```bash
node --inspect-brk --test math.test.js
```

Attach, pause on the thrown `TypeError` (reduce of empty array with no initial value), and fix `average`.
