## Goal

## Background

### Path traversal
Building file paths from user input (`join(uploads, req.query.file)`) lets attackers use `../` to read any file. Fix: resolve the path, then verify it is still inside the allowed root (`resolved.startsWith(root + sep)`), and reject null bytes and encoded tricks. You did this in P4.2.

### Command injection
`exec(\`convert ${userFile} out.png\`)` runs through a shell, so `file.png; rm -rf ~` executes both commands. Fix: use `execFile` / `spawn` with an **argument array** and no shell. Arguments are passed directly to the program, never interpreted by a shell.

### Prototype pollution
JavaScript objects inherit from `Object.prototype`. A naive deep-merge of user JSON like `{"__proto__": {"isAdmin": true}}` writes to the shared prototype, so **every** object suddenly has `isAdmin === true`. Fixes: reject `__proto__`, `constructor`, and `prototype` keys; use `Object.create(null)` or `Map` for dictionaries keyed by user input; validate input against a schema that forbids unknown keys.

### ReDoS (regular expression denial of service)
Regexes with nested quantifiers, like `/^(a+)+$/`, can take **exponential** time on crafted input. Because regex matching is synchronous, one request can freeze the whole event loop. Fixes: avoid nested quantifiers and ambiguous alternation, cap input length before matching, and test suspicious patterns with long near-matching strings.

### SSRF (server-side request forgery)
If your server fetches user-supplied URLs (webhooks, link previews, image imports), attackers can point it at internal services: `http://169.254.169.254/` (cloud metadata with credentials), `http://localhost:6379`, internal admin panels. Fixes: allow only `https:`, resolve the hostname and reject private, loopback, and link-local IPs, disable redirects (or re-check each hop), and set timeouts and size limits.

### Resource exhaustion
Unlimited request bodies, unbounded `JSON.parse` of huge input, missing timeouts, and unbounded concurrency all let a single client take down a server. Always set body limits, timeouts, and rate limits.

### Dependencies are your biggest attack surface
Most code in a Node app comes from npm. Practices: run `npm audit` in CI, commit the lockfile and install with `npm ci`, minimise dependencies, review new packages (maintainers, downloads, install scripts), and pin CI actions. Consider `--ignore-scripts` for installs that don't need native builds.

### The Node.js permission model
`node --permission` starts Node with **no** file system, child process, worker, or native addon access, and you grant only what's needed: `--allow-fs-read=/app`, `--allow-fs-write=/app/data`, `--allow-child-process`. A compromised dependency then can't read `~/.ssh` or spawn a shell. (It's a defence-in-depth layer, not a sandbox for untrusted code.)

### Secrets and errors
Never log secrets or full request bodies, never return stack traces to clients, and never commit `.env` files.

### 1. Path traversal

```js
// traversal.js — VULNERABLE
import { createServer } from 'node:http';
import { readFile } from 'node:fs/promises';
import { join } from 'node:path';

createServer(async (req, res) => {
  const file = new URL(req.url, 'http://x').searchParams.get('file');
  try {
    res.end(await readFile(join(import.meta.dirname, 'public', file)));
  } catch {
    res.writeHead(404).end('not found');
  }
}).listen(3000);
```

```bash
curl 'localhost:3000/?file=readme.txt'
curl 'localhost:3000/?file=../.env'          # leaks the secret
```

**Fix:** resolve against the root and verify containment:

```js
import { resolve, sep } from 'node:path';
const ROOT = resolve(import.meta.dirname, 'public');
const target = resolve(ROOT, file ?? '');
if (file?.includes('\0') || !target.startsWith(ROOT + sep)) return res.writeHead(403).end('forbidden');
```

### 2. Command injection

```js
// injection.js — VULNERABLE
import { exec } from 'node:child_process';

const filename = process.argv[2];              // imagine this came from a request
exec(`wc -l ${filename}`, (err, stdout) => console.log(stdout || err.message));
```

```bash
node injection.js package.json
node injection.js 'package.json; echo PWNED > pwned.txt' && ls pwned.txt
```

**Fix:**

```js
import { execFile } from 'node:child_process';
execFile('wc', ['-l', '--', filename], (err, stdout) => console.log(stdout || err.message));
```

The whole string is now one argument — `wc` simply reports that the file doesn't exist.

### 3. Prototype pollution

```js
// pollution.js — VULNERABLE
function merge(target, source) {
  for (const key in source) {
    if (typeof source[key] === 'object' && source[key] !== null) {
      target[key] ??= {};
      merge(target[key], source[key]);
    } else {
      target[key] = source[key];
    }
  }
  return target;
}

const userSettings = JSON.parse('{"theme":"dark","__proto__":{"isAdmin":true}}');
merge({}, userSettings);

const someOtherUser = {};
console.log('isAdmin on an unrelated object:', someOtherUser.isAdmin);   // true!
```

**Fix:** skip dangerous keys and only copy own properties:

```js
const FORBIDDEN = new Set(['__proto__', 'constructor', 'prototype']);
function safeMerge(target, source) {
  for (const key of Object.keys(source)) {
    if (FORBIDDEN.has(key)) continue;
    const value = source[key];
    if (value && typeof value === 'object' && !Array.isArray(value)) {
      if (!Object.hasOwn(target, key)) target[key] = {};
      safeMerge(target[key], value);
    } else {
      target[key] = value;
    }
  }
  return target;
}
```

Run with the fix and confirm `({}).isAdmin` is `undefined`. Also try `node --disable-proto=delete pollution.js` on the vulnerable version.

### 4. ReDoS

```js
// redos.js
const vulnerable = /^([a-zA-Z0-9]+\s?)*$/;      // nested quantifier
const safe = /^[a-zA-Z0-9]+(?:\s[a-zA-Z0-9]+)*$/;

for (const n of [16, 20, 24, 26]) {
  const evil = 'a'.repeat(n) + '!';
  let start = performance.now();
  vulnerable.test(evil);
  const slow = performance.now() - start;
  start = performance.now();
  safe.test(evil);
  console.log(`n=${n}: vulnerable ${slow.toFixed(0)}ms, safe ${(performance.now() - start).toFixed(3)}ms`);
}
```

Watch the vulnerable time roughly double with each extra character. Then add an input length cap (e.g. 200 characters) in front of any regex applied to user input.

### 5. SSRF guard

```js
// ssrf.js
import { lookup } from 'node:dns/promises';
import { BlockList, isIP } from 'node:net';

const blocked = new BlockList();
blocked.addSubnet('10.0.0.0', 8);
blocked.addSubnet('172.16.0.0', 12);
blocked.addSubnet('192.168.0.0', 16);
blocked.addSubnet('127.0.0.0', 8);
blocked.addSubnet('169.254.0.0', 16);   // link-local, incl. cloud metadata
blocked.addSubnet('0.0.0.0', 8);
blocked.addAddress('::1', 'ipv6');
blocked.addSubnet('fc00::', 7, 'ipv6');
blocked.addSubnet('fe80::', 10, 'ipv6');

export async function assertPublicUrl(raw) {
  const url = new URL(raw);
  if (url.protocol !== 'https:') throw new Error('only https URLs are allowed');
  const host = url.hostname.replace(/^\[|\]$/g, '');
  const addresses = isIP(host) ? [{ address: host, family: isIP(host) }] : await lookup(host, { all: true });
  for (const { address, family } of addresses) {
    if (blocked.check(address, family === 6 ? 'ipv6' : 'ipv4')) throw new Error(`blocked address ${address}`);
  }
  return url;
}

for (const u of ['https://example.com', 'http://example.com', 'https://127.0.0.1', 'https://169.254.169.254/latest/meta-data', 'https://localhost']) {
  try { await assertPublicUrl(u); console.log('allowed', u); }
  catch (err) { console.log('blocked', u, '-', err.message); }
}
```

Then fetch with `redirect: 'manual'` so a public URL can't redirect to an internal one. (A fully robust guard also pins the resolved IP for the actual connection to prevent DNS rebinding.)

### 7. Run with the permission model

```js
// perm.js
import { readFile } from 'node:fs/promises';
import { execSync } from 'node:child_process';

console.log((await readFile('public/readme.txt', 'utf8')).trim());
try { await readFile('.env', 'utf8'); console.log('read .env!'); } catch (err) { console.log('.env:', err.code); }
try { execSync('whoami'); console.log('spawned a process!'); } catch (err) { console.log('spawn:', err.code); }
```

```bash
node perm.js                                                   # everything allowed
node --permission \
  --allow-fs-read="$PWD/perm.js" --allow-fs-read="$PWD/package.json" --allow-fs-read="$PWD/public" \
  perm.js
```

With the permission model, reading `.env` and spawning processes both fail with `ERR_ACCESS_DENIED`. (`package.json` must be readable so Node can see `"type": "module"`. On Node versions before 22.13/23.5 the flag is `--experimental-permission`.)
