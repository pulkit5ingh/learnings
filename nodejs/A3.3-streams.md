**Phase:** 3 — File System & Streams

**Type:** Assignment

## Goal
Process data of any size with constant memory using streams, and understand backpressure well enough to never cause a memory blow-up.

## Background

### Why streams
`readFile` loads the whole file into memory. That's fine for a 10 KB config file and fatal for a 10 GB log. A stream delivers data in **chunks** (64 KB by default for files), so memory use stays flat regardless of input size — and processing can start before all the data has arrived.

Streams are everywhere in Node: files (`createReadStream`), HTTP requests and responses, sockets, `process.stdin/stdout`, compression (`zlib`), and crypto hashes.

### The four types
| Type | Description | Examples |
|------|-------------|----------|
| **Readable** | Source of data | `fs.createReadStream`, `req` on a server, `process.stdin` |
| **Writable** | Destination | `fs.createWriteStream`, `res` on a server, `process.stdout` |
| **Duplex** | Both, independently | TCP sockets |
| **Transform** | Duplex where output is computed from input | `zlib.createGzip()`, `crypto.createHash()` |

### Backpressure
If a readable produces data faster than a writable can consume it, chunks pile up in memory. Writables signal this: `writable.write(chunk)` **returns `false`** when its internal buffer exceeds `highWaterMark`. The producer must then stop and wait for the `'drain'` event. `pipe()` and `pipeline()` do this for you automatically. Writing in a loop while ignoring the return value is the classic way to exhaust memory.

### Always use `pipeline`
`a.pipe(b).pipe(c)` doesn't propagate errors or clean up: if `c` fails, `a` keeps reading and file descriptors leak. `pipeline(a, b, c)` from `node:stream/promises` wires them together, handles backpressure, **destroys every stream if any one fails**, and returns a promise. It also accepts async generator functions as transform stages.

### Async iteration
Every Readable is an async iterable: `for await (const chunk of readable)`. This is the simplest way to consume a stream, and it respects backpressure (the next chunk isn't read until your loop body finishes).

### Object mode
By default streams carry Buffers or strings. With `objectMode: true` they carry arbitrary JavaScript values — useful for pipelines that parse records (lines → objects → filtered objects → CSV).

### 1. Memory: readFile vs stream

```bash
mkdir a3-3-streams && cd a3-3-streams
npm init -y && npm pkg set type=module
node -e "require('fs').writeFileSync('big.txt', 'hello stream world\n'.repeat(15_000_000))"   # ~285 MB
```

```js
// memory.js
import { readFile } from 'node:fs/promises';
import { createReadStream } from 'node:fs';

const mb = () => `${Math.round(process.memoryUsage().rss / 1024 / 1024)} MB`;
const mode = process.argv[2];

if (mode === 'buffer') {
  const data = await readFile('big.txt');
  console.log('bytes:', data.length, 'rss:', mb());
} else {
  let bytes = 0;
  for await (const chunk of createReadStream('big.txt')) bytes += chunk.length;
  console.log('bytes:', bytes, 'rss:', mb());
}
```

node memory.js buffer

### 2. Copy and compress with pipeline

```js
// gzip.js
import { createReadStream, createWriteStream } from 'node:fs';
import { createGzip, createGunzip } from 'node:zlib';
import { pipeline } from 'node:stream/promises';

console.time('gzip');
await pipeline(createReadStream('big.txt'), createGzip(), createWriteStream('big.txt.gz'));
console.timeEnd('gzip');

await pipeline(createReadStream('big.txt.gz'), createGunzip(), createWriteStream('roundtrip.txt'));
console.log('round trip complete');

// Error propagation: a missing source rejects the whole pipeline and closes the destination
try {
  await pipeline(createReadStream('nope.txt'), createGzip(), createWriteStream('nope.gz'));
} catch (err) {
  console.log('pipeline failed:', err.code);
}
```

### 3. A Transform stream

```js
// upper.js
import { Transform } from 'node:stream';
import { pipeline } from 'node:stream/promises';

const upper = new Transform({
  transform(chunk, encoding, callback) {
    callback(null, chunk.toString().toUpperCase());
  },
});

await pipeline(process.stdin, upper, process.stdout);
```

echo "make me loud" | node upper.js

### 4. Async generators as pipeline stages

```js
// lines.js
import { createReadStream, createWriteStream } from 'node:fs';
import { pipeline } from 'node:stream/promises';

// Split arbitrary chunks into complete lines (a chunk can end mid-line!)
async function* splitLines(source) {
  let leftover = '';
  for await (const chunk of source) {
    const parts = (leftover + chunk).split('\n');
    leftover = parts.pop();
    yield* parts;
  }
  if (leftover) yield leftover;
}

// Keep every millionth line, prefixed with its line number
async function* sampleLines(source) {
  let n = 0;
  for await (const line of source) {
    if (++n % 1_000_000 === 0) yield `${n}: ${line}\n`;
  }
  yield `total lines: ${n}\n`;
}

await pipeline(
  createReadStream('big.txt', { encoding: 'utf8' }),
  splitLines,
  sampleLines,
  createWriteStream('sampled-lines.txt'),
);
console.log('processed every line with constant memory → sampled-lines.txt');
```

### 5. Implement a Readable and a Writable

```js
// custom.js
import { Readable, Writable } from 'node:stream';
import { pipeline } from 'node:stream/promises';
import { setTimeout as sleep } from 'node:timers/promises';

// Readable from an async generator (object mode)
const numbers = Readable.from((async function* () {
  for (let i = 1; i <= 10; i++) yield { i, square: i * i };
})());

// Slow writable sink
class SlowSink extends Writable {
  constructor() { super({ objectMode: true, highWaterMark: 2 }); }
  async _write(obj, _enc, callback) {
    await sleep(50);
    console.log('wrote', obj);
    callback();
  }
}

await pipeline(numbers, new SlowSink());
```

### 6. Backpressure by hand

```js
// backpressure.js
import { createWriteStream } from 'node:fs';
import { once } from 'node:events';

const out = createWriteStream('numbers.txt');
const mb = () => Math.round(process.memoryUsage().rss / 1024 / 1024);

// WRONG version: uncomment to see memory explode
// for (let i = 0; i < 5_000_000; i++) out.write(`${i}\n`);

let drains = 0;
for (let i = 0; i < 5_000_000; i++) {
  if (!out.write(`${i}\n`)) {
    drains++;
    await once(out, 'drain');           // wait until the buffer empties
  }
}
out.end();
await once(out, 'finish');
console.log(`done, waited for drain ${drains} times, rss ${mb()} MB`);
```

Run the wrong version and the correct version and compare peak memory with `/usr/bin/time -l` (macOS) or `/usr/bin/time -v` (Linux).

### 7. Streams over HTTP

```js
// serve.js
import { createServer } from 'node:http';
import { createReadStream } from 'node:fs';
import { createGzip } from 'node:zlib';
import { pipeline } from 'node:stream/promises';

createServer(async (req, res) => {
  res.writeHead(200, { 'content-type': 'text/plain', 'content-encoding': 'gzip' });
  try {
    await pipeline(createReadStream('big.txt'), createGzip(), res);
  } catch (err) {
    console.error('client went away or read failed:', err.code);
  }
}).listen(3000, () => console.log('curl --compressed localhost:3000 | wc -c'));
```

Cancel the curl midway with Ctrl+C — `pipeline` logs the error and closes the file stream instead of leaking it.
