## Goal
Call other services reliably from Node: handle errors and status codes correctly, stream large downloads, time out slow servers, and retry safely.

## Background

### fetch is built in
Since Node 18, `fetch`, `Request`, `Response`, `Headers`, and `FormData` are globals, implemented by the **undici** library. They follow the browser standard, so the same knowledge works on both sides.

### fetch only rejects on network failure
A `404` or `500` response does **not** reject the promise — `fetch` resolves with a `Response` whose `res.ok` is `false`. It rejects only when no response arrives at all (DNS failure, connection refused, reset, abort). You must check `res.ok` / `res.status` yourself.

```js
const res = await fetch(url);
if (!res.ok) throw new Error(`HTTP ${res.status}`);
const data = await res.json();
```

### Bodies are streams and can be read once
`res.json()`, `res.text()`, `res.arrayBuffer()`, and `res.blob()` consume the body. Calling a second one throws. `res.body` is a web `ReadableStream`; convert it with `Readable.fromWeb(res.body)` to pipe it into Node streams (e.g. a file). If you don't need the body, call `res.body?.cancel()` so the connection can be reused.

### Timeouts
`fetch` has no default timeout. Always pass `signal: AbortSignal.timeout(ms)`. A timed-out request rejects with a `TimeoutError`.

### Retry only what is safe
Retry **transient** failures — network errors, timeouts, `502/503/504`, `429` (respecting `Retry-After`) — with exponential backoff and jitter. Only retry **idempotent** requests (GET, HEAD, PUT, DELETE) automatically; retrying a POST can create duplicates unless the API supports idempotency keys.

### Lower-level: node:http / node:https
`http.request()` and `http.get()` give full control (raw sockets, custom agents, trailers) but a more verbose callback/stream API. Their **`Agent`** manages connection pooling; `keepAlive` reuses TCP/TLS connections across requests, which matters a lot for latency.

// basic.js
async function getJson(url) {
  const res = await fetch(url, { headers: { accept: 'application/json' } });
  if (!res.ok) {

### 4. Stream a large download to disk

```js
// download.js
import { createWriteStream } from 'node:fs';
import { Readable, Transform } from 'node:stream';
import { pipeline } from 'node:stream/promises';

const url = process.argv[2] ?? 'https://nodejs.org/dist/v22.11.0/node-v22.11.0-linux-x64.tar.xz';
const res = await fetch(url, { signal: AbortSignal.timeout(120_000) });
if (!res.ok || !res.body) throw new Error(`download failed: ${res.status}`);

const total = Number(res.headers.get('content-length')) || 0;
let received = 0;
const progress = new Transform({
  transform(chunk, _enc, cb) {
    received += chunk.length;
    if (total) process.stderr.write(`\r${((received / total) * 100).toFixed(1)}%`);
    cb(null, chunk);
  },
});

await pipeline(Readable.fromWeb(res.body), progress, createWriteStream('download.bin'));
process.stderr.write(`\nsaved ${received} bytes, rss ${Math.round(process.memoryUsage().rss / 1e6)} MB\n`);
```

Memory stays low even for a large file. (Use any large public file URL if that one is unavailable.)

### 5. A resilient client: timeout + retry + Retry-After

```js
// client.js
import { setTimeout as sleep } from 'node:timers/promises';

const RETRYABLE_STATUS = new Set([429, 502, 503, 504]);
const IDEMPOTENT = new Set(['GET', 'HEAD', 'PUT', 'DELETE', 'OPTIONS']);

export async function request(url, { method = 'GET', retries = 3, timeoutMs = 5000, ...init } = {}) {
  const canRetry = IDEMPOTENT.has(method);
  for (let attempt = 0; ; attempt++) {
    try {
      const res = await fetch(url, { method, ...init, signal: AbortSignal.timeout(timeoutMs) });
      if (!RETRYABLE_STATUS.has(res.status) || !canRetry || attempt >= retries) return res;
      const retryAfter = Number(res.headers.get('retry-after'));
      await res.body?.cancel();
      const wait = Number.isFinite(retryAfter) && retryAfter > 0 ? retryAfter * 1000 : backoff(attempt);
      console.error(`  ${res.status}, retrying in ${Math.round(wait)}ms`);
      await sleep(wait);
    } catch (err) {
      if (!canRetry || attempt >= retries) throw err;
      const wait = backoff(attempt);
      console.error(`  ${err.name}: ${err.cause?.code ?? err.message}, retrying in ${Math.round(wait)}ms`);
      await sleep(wait);
    }
  }
}

const backoff = (attempt) => Math.min(250 * 2 ** attempt, 5000) + Math.random() * 100;
```

```js
// use-client.js
import { request } from './client.js';

let res = await request('https://httpbin.org/status/503', { retries: 2 });
console.log('final status:', res.status);

try {
  await request('https://httpbin.org/delay/5', { timeoutMs: 1000, retries: 1 });
} catch (err) {
  console.log('gave up:', err.name);
}

res = await request('https://httpbin.org/status/503', { method: 'POST', retries: 3 });
console.log('POST not retried:', res.status);
```

### 6. node:http and keep-alive agents

```js
// agent.js
import https from 'node:https';

function get(url, agent) {
  return new Promise((resolve, reject) => {
    const req = https.get(url, { agent }, (res) => {
      res.resume();                               // discard body so the socket is freed
      res.on('end', () => resolve(res.statusCode));
    });
    req.on('error', reject);
    req.setTimeout(5000, () => req.destroy(new Error('timeout')));
  });
}

for (const keepAlive of [false, true]) {
  const agent = new https.Agent({ keepAlive, maxSockets: 10 });
  const start = performance.now();
  for (let i = 0; i < 10; i++) await get('https://example.com/', agent);
  console.log(`keepAlive=${keepAlive}: ${Math.round(performance.now() - start)}ms for 10 sequential requests`);
  agent.destroy();
}
```

Keep-alive avoids a new TCP + TLS handshake per request. (Global `fetch` already reuses connections by default.)
