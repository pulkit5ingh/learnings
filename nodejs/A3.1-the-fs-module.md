## Goal
Read and write files safely and efficiently with `node:fs`, handle every common error code, and avoid corrupting data.

## Background

### Three flavours of the same API
| Style | Import | Use when |
|-------|--------|----------|
| Promises | `node:fs/promises` | Default choice in application code |
| Callbacks | `node:fs` | Legacy code, or the rare hot path where callbacks are measurably faster |
| Sync | `node:fs` (`readFileSync`…) | CLI startup, config loading, scripts — **never** inside a request handler |

Sync calls block the event loop for the full duration of the disk operation. On a server that means every other request waits.

### Error codes you must recognise
fs errors carry a `code` property. Branch on it rather than on the message:

| Code | Meaning |
|------|---------|
| `ENOENT` | No such file or directory |
| `EEXIST` | Already exists (e.g. `mkdir` without `recursive`, `open` with `wx`) |
| `EACCES` / `EPERM` | Permission denied |
| `EISDIR` / `ENOTDIR` | Expected a file but got a directory, or vice versa |
| `EMFILE` | Too many open files — you opened too many at once |
| `ENOTEMPTY` | Directory not empty |

### Check-then-act is a race
`if (await exists(path)) await readFile(path)` is wrong: the file can be deleted between the two calls. Just attempt the operation and handle `ENOENT`. `fs.access` is for diagnostics, not control flow.

### Flags
`writeFile(path, data, { flag })` — `'w'` truncate/create (default), `'a'` append, `'wx'` create **only if it doesn't exist** (fails with `EEXIST` — an atomic "create once"), `'r+'` read/write existing.

### Atomic writes
`writeFile` is not atomic: if the process crashes mid-write, the file is left half-written. The standard fix is **write to a temp file in the same directory, then `rename`** over the target. `rename` within one filesystem is atomic on POSIX systems.

### File handles
`fs.promises.open()` returns a `FileHandle` for fine-grained control: read/write at positions, `stat`, `sync` (flush to disk), and `close`. Always close handles (use `try/finally`), or you'll leak file descriptors until `EMFILE`.

### Encodings and Buffers
Without an encoding, `readFile` returns a `Buffer`. Pass `'utf8'` to get a string. Use Buffers for binary data (images, archives).

### 2. Handle errors by code

```js
// errors.js
import { readFile, mkdir, rmdir, writeFile } from 'node:fs/promises';

async function readOrDefault(path, fallback) {
  try {
    return await readFile(path, 'utf8');
  } catch (err) {
    if (err.code === 'ENOENT') return fallback;
    throw err;                                   // anything else is unexpected
  }
}

console.log(await readOrDefault('missing.json', '{}'));

try { await mkdir('dir'); await mkdir('dir'); } catch (err) { console.log(err.code); }        // EEXIST
try { await readFile('dir'); } catch (err) { console.log(err.code); }                            // EISDIR
await writeFile('dir/file.txt', 'x');
try { await rmdir('dir'); } catch (err) { console.log(err.code); }                               // ENOTEMPTY
try { await writeFile('/root/nope.txt', 'x'); } catch (err) { console.log(err.code); }           // EACCES (non-root)
```

### 3. Create exactly once with `wx`

```js
// lockfile.js
import { writeFile, unlink } from 'node:fs/promises';

async function acquireLock(path) {
  try {
    await writeFile(path, String(process.pid), { flag: 'wx' });
    return true;
  } catch (err) {
    if (err.code === 'EEXIST') return false;
    throw err;
  }
}

if (await acquireLock('app.lock')) {
  console.log('lock acquired, doing work for 5s…');
  setTimeout(async () => { await unlink('app.lock'); console.log('released'); }, 5000);
} else {
  console.error('another instance is running');
  process.exitCode = 1;
}
```

Run it in two terminals at the same time.

### 4. Inspect files with stat

```js
// stat.js
import { stat, lstat, symlink, rm } from 'node:fs/promises';

const s = await stat('package.json');
console.log({
  isFile: s.isFile(),
  isDirectory: s.isDirectory(),
  size: s.size,
  modified: s.mtime.toISOString(),
  mode: (s.mode & 0o777).toString(8),
});

await rm('link.json', { force: true });
await symlink('package.json', 'link.json');
console.log('stat follows link:', (await stat('link.json')).isSymbolicLink());   // false
console.log('lstat sees link:', (await lstat('link.json')).isSymbolicLink());    // true
```

### 5. Atomic JSON writes

```js
// atomic.js
import { writeFile, rename, readFile, open } from 'node:fs/promises';
import { dirname, join, basename } from 'node:path';
import { randomUUID } from 'node:crypto';

export async function writeJsonAtomic(path, data) {
  const tmp = join(dirname(path), `.${basename(path)}.${randomUUID()}.tmp`);
  const handle = await open(tmp, 'w');
  try {
    await handle.writeFile(JSON.stringify(data, null, 2));
    await handle.sync();              // flush to disk before rename
  } finally {
    await handle.close();
  }
  await rename(tmp, path);            // atomic replace
}

await writeJsonAtomic('state.json', { counter: 1, updatedAt: new Date() });
console.log(await readFile('state.json', 'utf8'));
```

### 6. File handles and positional reads

```js
// handle.js
import { open, writeFile } from 'node:fs/promises';

await writeFile('alphabet.txt', 'abcdefghijklmnopqrstuvwxyz');

const fh = await open('alphabet.txt', 'r');
try {
  const buf = Buffer.alloc(5);
  const { bytesRead } = await fh.read(buf, 0, 5, 10);   // read 5 bytes at position 10
  console.log(bytesRead, buf.toString());               // 5 'klmno'
  console.log('size:', (await fh.stat()).size);
} finally {
  await fh.close();
}
```

### 7. See sync calls block a server

```js
// block-server.js
import { createServer } from 'node:http';
import { readFileSync, writeFileSync } from 'node:fs';
import { readFile } from 'node:fs/promises';

writeFileSync('big.bin', Buffer.alloc(200 * 1024 * 1024));   // 200 MB test file

createServer(async (req, res) => {
  if (req.url === '/sync') readFileSync('big.bin');
  if (req.url === '/async') await readFile('big.bin');
  res.end(`${req.url} done\n`);
}).listen(3000);
```

In one terminal run `curl localhost:3000/sync & curl localhost:3000/` — the second request waits for the first. Repeat with `/async`. Delete `big.bin` afterwards.
