## Goal
Scale a single HTTP server across all CPU cores with the cluster module, keep it alive through crashes, and restart it without dropping requests.

## Background

### One process, one core
A Node process runs JavaScript on one thread, so an HTTP server uses one CPU core no matter how big the machine is. **`node:cluster`** forks the same script into multiple processes that all accept connections on the **same port**.

### Primary and workers
- The **primary** process (`cluster.isPrimary`) doesn't serve requests. It forks workers with `cluster.fork()`, watches them, and restarts them when they die.
- Each **worker** runs your server code. When it calls `server.listen(3000)`, the listen request is routed to the primary, which owns the actual socket.
- By default (except on Windows) the primary accepts connections and hands them to workers **round-robin**.

Primary and workers communicate over IPC (`worker.send()` / `process.on('message')`), like `fork()` in A6.1.

### Workers share nothing
Each worker has its own memory. In-memory sessions, caches, rate-limit counters, and WebSocket rooms are **not** shared — a user's next request may hit a different worker. Put shared state in Redis or a database, or use sticky sessions at the load balancer.

### Resilience
If a worker crashes, the primary gets an `'exit'` event and forks a replacement. Guard against **crash loops** (a bug that kills every new worker instantly) by rate-limiting restarts.

### Zero-downtime restarts
To deploy new code without dropping requests, restart workers **one at a time**: fork a new worker, wait until it's `'listening'`, then tell an old worker to stop accepting connections (`server.close()`), finish in-flight requests, and exit. This is what `pm2 reload` does.

### When not to use cluster
In containers and Kubernetes, it's usually better to run **one Node process per container** and let the orchestrator run more replicas — simpler, and failures are isolated. Cluster shines on single VMs or bare-metal servers.

// cluster.js
import cluster from 'node:cluster';
import { availableParallelism } from 'node:os';
import { createServer } from 'node:http';

if (cluster.isPrimary) {
  const n = availableParallelism();
  console.log(`primary ${process.pid} forking ${n} workers`);
  for (let i = 0; i < n; i++) cluster.fork();
  cluster.on('online', (w) => console.log(`worker ${w.process.pid} online`));
} else {
  createServer((req, res) => {

  }).listen(3000);
}

### 3. Crash recovery with crash-loop protection

```js
// resilient.js
import cluster from 'node:cluster';
import { availableParallelism } from 'node:os';
import { createServer } from 'node:http';

if (cluster.isPrimary) {
  const restarts = [];
  for (let i = 0; i < availableParallelism(); i++) cluster.fork();

  cluster.on('exit', (worker, code, signal) => {
    if (worker.exitedAfterDisconnect) return;           // intentional shutdown
    console.log(`worker ${worker.process.pid} died (${signal ?? code})`);
    const now = Date.now();
    restarts.push(now);
    while (restarts[0] < now - 60_000) restarts.shift();
    if (restarts.length > 10) {
      console.error('more than 10 crashes in a minute — giving up');
      process.exit(1);
    }
    cluster.fork();
  });
} else {
  createServer((req, res) => {
    if (req.url === '/crash') throw new Error('boom');   // uncaught → worker dies
    res.end(`ok from ${process.pid}\n`);
  }).listen(3000);
}
```

```bash
curl localhost:3000/crash; curl localhost:3000/       # service keeps answering
```

### 4. Rolling restart with graceful worker shutdown

```js
// rolling.js
import cluster from 'node:cluster';
import { availableParallelism } from 'node:os';
import { createServer } from 'node:http';
import { once } from 'node:events';
import { setTimeout as sleep } from 'node:timers/promises';

if (cluster.isPrimary) {
  for (let i = 0; i < availableParallelism(); i++) cluster.fork();

  async function rollingRestart() {
    const old = Object.values(cluster.workers);
    console.log(`rolling restart of ${old.length} workers`);
    for (const worker of old) {
      const fresh = cluster.fork();
      await once(fresh, 'listening');                   // new one ready first
      worker.send('shutdown');
      worker.disconnect();                              // marks exitedAfterDisconnect
      await once(worker, 'exit');
      console.log(`replaced ${worker.process.pid} → ${fresh.process.pid}`);
    }
    console.log('rolling restart complete');
  }

  process.on('SIGHUP', rollingRestart);                 // kill -HUP <primary pid>
  console.log(`primary ${process.pid} — send SIGHUP to reload`);
} else {
  const server = createServer(async (req, res) => {
    await sleep(1000);                                  // slow request, to prove none are dropped
    res.end(`done by ${process.pid}\n`);
  }).listen(3000);

  process.on('message', (msg) => {
    if (msg === 'shutdown') {
      server.close(() => process.exit(0));              // stop accepting, finish in-flight, exit
      setTimeout(() => process.exit(1), 10_000).unref();
    }
  });
}
```

```bash
node rolling.js
npx autocannon -c 20 -d 15 localhost:3000 &
sleep 3 && kill -HUP <primary pid>
# autocannon should report 0 errors
```
