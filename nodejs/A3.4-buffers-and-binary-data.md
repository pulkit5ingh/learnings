## Background

### What a Buffer is
A `Buffer` is a fixed-length sequence of bytes (values 0–255). It is a subclass of `Uint8Array`, so every `TypedArray` method works on it, plus Node-specific helpers for encodings and numbers. Buffer memory lives outside the V8 heap, which makes them efficient for I/O.

### Creating Buffers
| Method | Notes |
|--------|-------|
| `Buffer.from('héllo', 'utf8')` | From a string with an encoding |
| `Buffer.from([0x68, 0x69])` | From bytes |
| `Buffer.from(arrayBuffer)` | Shares memory with an `ArrayBuffer` |
| `Buffer.alloc(n)` | `n` zero-filled bytes — safe |
| `Buffer.allocUnsafe(n)` | Faster but **may contain old memory** — only use if you overwrite every byte |
| `Buffer.concat([a, b])` | Join buffers |

### Encodings
`'utf8'` (default), `'hex'`, `'base64'`, `'base64url'`, `'latin1'`, `'ascii'`, `'utf16le'`. `buf.toString(encoding)` decodes, `Buffer.from(str, encoding)` encodes. Base64 is how binary travels through text-only channels (JSON, email, data URLs); `base64url` is the URL-safe variant used in JWTs.

### Bytes ≠ characters
`'é'.length` is 1 but `Buffer.byteLength('é')` is 2 in UTF-8, and an emoji can be 4 bytes. Slicing a Buffer in the middle of a multi-byte character and calling `toString()` produces `�`. When decoding chunked text from a stream, use `string_decoder` or `TextDecoder` with `{ stream: true }` — or simply set an encoding on the stream, which uses a decoder internally.

### Views share memory
`buf.subarray(start, end)` (and the legacy `buf.slice`) return a **view** of the same memory, not a copy. Modifying the view modifies the original. Use `Buffer.from(view)` or `buf.subarray().copy()` semantics when you need an independent copy.

### Reading numbers and endianness
Binary formats store numbers as fixed-width integers in a specified byte order: **big-endian** (most significant byte first — network order, PNG) or **little-endian** (x86, most file formats like WAV, ZIP). Buffers provide `readUInt8`, `readUInt16BE/LE`, `readUInt32BE/LE`, `readInt32LE`, `readBigUInt64LE`, `readFloatLE`, `readDoubleBE`… and the matching `write*` methods. `DataView` offers the same in standard JavaScript.

### 4. Write and read a binary record format

Design a fixed 16-byte record: `uint32 id (BE) | uint16 age (BE) | uint8 flags | uint8 nameLength | 8 bytes name (padded)`.

```js
// records.js
import { writeFile, readFile } from 'node:fs/promises';

const RECORD_SIZE = 16;

function encode({ id, age, active, admin, name }) {
  const buf = Buffer.alloc(RECORD_SIZE);
  buf.writeUInt32BE(id, 0);
  buf.writeUInt16BE(age, 4);
  buf.writeUInt8((active ? 1 : 0) | (admin ? 2 : 0), 6);   // bit flags
  const nameBytes = Buffer.from(name, 'utf8').subarray(0, 8);
  buf.writeUInt8(nameBytes.length, 7);
  nameBytes.copy(buf, 8);
  return buf;
}

function decode(buf) {
  const flags = buf.readUInt8(6);
  const nameLength = buf.readUInt8(7);
  return {
    id: buf.readUInt32BE(0),
    age: buf.readUInt16BE(4),
    active: Boolean(flags & 1),
    admin: Boolean(flags & 2),
    name: buf.toString('utf8', 8, 8 + nameLength),
  };
}

const users = [
  { id: 1, age: 36, active: true, admin: true, name: 'ada' },
  { id: 2, age: 54, active: false, admin: false, name: 'linus' },
  { id: 3, age: 29, active: true, admin: false, name: 'grace' },
];

await writeFile('users.bin', Buffer.concat(users.map(encode)));

const data = await readFile('users.bin');
console.log('file size:', data.length);
for (let off = 0; off < data.length; off += RECORD_SIZE) {
  console.log(decode(data.subarray(off, off + RECORD_SIZE)));
}
```

Inspect the file with `xxd users.bin` (or `hexdump -C`) and find each field.

### 5. Parse a real format: PNG dimensions

A PNG starts with an 8-byte signature, then the `IHDR` chunk: 4-byte length, 4-byte type `"IHDR"`, then width and height as big-endian uint32.

```js
// png-size.js
import { open } from 'node:fs/promises';

const PNG_SIGNATURE = Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]);

export async function pngSize(path) {
  const fh = await open(path, 'r');
  try {
    const header = Buffer.alloc(24);
    await fh.read(header, 0, 24, 0);                  // read only the first 24 bytes
    if (!header.subarray(0, 8).equals(PNG_SIGNATURE)) throw new Error('not a PNG');
    if (header.toString('ascii', 12, 16) !== 'IHDR') throw new Error('missing IHDR');
    return { width: header.readUInt32BE(16), height: header.readUInt32BE(20) };
  } finally {
    await fh.close();
  }
}

console.log(await pngSize(process.argv[2]));
```

Download any PNG and run `node png-size.js image.png`. Try it on a JPEG to see the signature check fail.

### 6. Endianness and DataView

```js
// endian.js
const buf = Buffer.alloc(4);
buf.writeUInt32BE(0x12345678);
console.log('BE:', buf);                 // <Buffer 12 34 56 78>
buf.writeUInt32LE(0x12345678);
console.log('LE:', buf);                 // <Buffer 78 56 34 12>

const view = new DataView(buf.buffer, buf.byteOffset, buf.byteLength);
console.log(view.getUint32(0, true).toString(16));   // true = little-endian

const f = Buffer.alloc(8);
f.writeDoubleLE(Math.PI);
console.log(f, f.readDoubleLE());
```
