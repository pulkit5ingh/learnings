## Goal
Encrypt and decrypt data correctly with AES-256-GCM — and understand each input well enough to avoid the mistakes that make encryption useless.

## Background

### Use authenticated encryption
Encryption alone hides data but doesn't stop tampering: with modes like AES-CBC or AES-CTR an attacker can flip bits in the ciphertext and change the plaintext predictably. **Authenticated encryption** (AEAD) both encrypts and produces an **authentication tag**; decryption fails if a single bit of ciphertext, tag, or associated data was changed. **AES-256-GCM** is the standard choice (ChaCha20-Poly1305 is the alternative).

### The inputs
| Input | Size | Rules |
|-------|------|-------|
| **Key** | 32 bytes for AES-256 | Random (`randomBytes(32)`) or derived from a password with a KDF. Never a raw password string. Keep it secret. |
| **IV / nonce** | 12 bytes for GCM | Random per encryption. **Never reuse an IV with the same key** — GCM nonce reuse breaks confidentiality and lets attackers forge messages. Not secret: store it with the ciphertext. |
| **Auth tag** | 16 bytes | Produced by encryption, required for decryption. Store it with the ciphertext. |
| **AAD** (optional) | any | "Additional authenticated data" — not encrypted, but bound to the ciphertext (e.g. a record ID or version). Decryption fails if it doesn't match. |

### Keys from passwords
To encrypt with a password, derive a key with a slow KDF (scrypt from A5.2) and a random salt. Store the salt (and KDF parameters) with the ciphertext so you can derive the same key to decrypt.

### An envelope format
A ciphertext you can't decrypt later is useless, so define a self-describing format, e.g.:

```
version(1) | salt(16) | iv(12) | tag(16) | ciphertext(…)
```

Versioning lets you change algorithms later. Encoding the whole thing as base64 makes it storable as text.

### Key management is the hard part
Encryption moves the problem from "protect the data" to "protect the key." Never hard-code keys or commit them. Load them from the environment or a secrets manager, support **rotation** (key IDs in the envelope), and use **envelope encryption** at scale: a data key encrypts the data, and a master key (often in a KMS) encrypts the data key.

```js
// basic.js
import { createCipheriv, createDecipheriv, randomBytes } from 'node:crypto';

const key = randomBytes(32);

function encrypt(plaintext) {
  const iv = randomBytes(12);
  const cipher = createCipheriv('aes-256-gcm', key, iv);
  const ciphertext = Buffer.concat([cipher.update(plaintext, 'utf8'), cipher.final()]);
  return { iv, ciphertext, tag: cipher.getAuthTag() };
}

function decrypt({ iv, ciphertext, tag }) {
  const decipher = createDecipheriv('aes-256-gcm', key, iv);
  decipher.setAuthTag(tag);
  return Buffer.concat([decipher.update(ciphertext), decipher.final()]).toString('utf8');
}

const box = encrypt('card ending 4242, expires 09/29');
console.log('ciphertext:', box.ciphertext.toString('hex'));
console.log('decrypted:', decrypt(box));

const box2 = encrypt('card ending 4242, expires 09/29');
console.log('same plaintext, different ciphertext:', !box.ciphertext.equals(box2.ciphertext));
```

### 3. A versioned, password-based envelope

```js
// envelope.js
import { createCipheriv, createDecipheriv, randomBytes, scryptSync } from 'node:crypto';

const VERSION = 1;
const SCRYPT = { N: 2 ** 15, r: 8, p: 1, maxmem: 64 * 1024 * 1024 };

const deriveKey = (password, salt) => scryptSync(password, salt, 32, SCRYPT);

export function seal(plaintext, password, aad = '') {
  const salt = randomBytes(16);
  const iv = randomBytes(12);
  const cipher = createCipheriv('aes-256-gcm', deriveKey(password, salt), iv);
  cipher.setAAD(Buffer.from(aad));
  const ct = Buffer.concat([cipher.update(plaintext, 'utf8'), cipher.final()]);
  return Buffer.concat([Buffer.from([VERSION]), salt, iv, cipher.getAuthTag(), ct]).toString('base64');
}

export function open(sealed, password, aad = '') {
  const buf = Buffer.from(sealed, 'base64');
  if (buf.length < 1 + 16 + 12 + 16) throw new Error('ciphertext too short');
  if (buf[0] !== VERSION) throw new Error(`unsupported version ${buf[0]}`);
  const salt = buf.subarray(1, 17);
  const iv = buf.subarray(17, 29);
  const tag = buf.subarray(29, 45);
  const ct = buf.subarray(45);
  const decipher = createDecipheriv('aes-256-gcm', deriveKey(password, salt), iv);
  decipher.setAAD(Buffer.from(aad));
  decipher.setAuthTag(tag);
  try {
    return Buffer.concat([decipher.update(ct), decipher.final()]).toString('utf8');
  } catch {
    throw new Error('decryption failed: wrong password or corrupted data');
  }
}
```

```js
// try-envelope.js
import { seal, open } from './envelope.js';

const sealed = seal('the launch code is 0000', 'hunter2', 'user:42');
console.log(sealed);
console.log(open(sealed, 'hunter2', 'user:42'));

for (const [label, pw, aad] of [['wrong password', 'hunter3', 'user:42'], ['wrong AAD', 'hunter2', 'user:43']]) {
  try { open(sealed, pw, aad); } catch (err) { console.log(`${label}: ${err.message}`); }
}
```

The AAD binds the ciphertext to `user:42`: copying user 42's encrypted field into user 43's row makes it undecryptable.

### 4. Encrypt a file as a stream

```js
// encrypt-file.js
import { createCipheriv, createDecipheriv, randomBytes } from 'node:crypto';
import { createReadStream, createWriteStream } from 'node:fs';
import { open as openFile } from 'node:fs/promises';
import { pipeline } from 'node:stream/promises';

const key = Buffer.from(process.env.FILE_KEY ?? randomBytes(32).toString('hex'), 'hex');

export async function encryptFile(src, dest) {
  const iv = randomBytes(12);
  const cipher = createCipheriv('aes-256-gcm', key, iv);
  const out = createWriteStream(dest);
  out.write(iv);                                            // header: iv(12)
  await pipeline(createReadStream(src), cipher, out);
  const fh = await openFile(dest, 'a');                     // trailer: tag(16)
  await fh.write(cipher.getAuthTag());
  await fh.close();
}

export async function decryptFile(src, dest) {
  const fh = await openFile(src, 'r');
  const { size } = await fh.stat();
  const iv = Buffer.alloc(12), tag = Buffer.alloc(16);
  await fh.read(iv, 0, 12, 0);
  await fh.read(tag, 0, 16, size - 16);
  await fh.close();

  const decipher = createDecipheriv('aes-256-gcm', key, iv);
  decipher.setAuthTag(tag);
  // Note: plaintext is written before the tag is checked at the end — write to a temp
  // file and only rename it into place if pipeline() succeeds.
  await pipeline(createReadStream(src, { start: 12, end: size - 17 }), decipher, createWriteStream(dest));
}

await encryptFile('package.json', 'package.json.enc');
await decryptFile('package.json.enc', 'package.decrypted.json');
console.log('round trip ok — compare with: diff package.json package.decrypted.json');
```
