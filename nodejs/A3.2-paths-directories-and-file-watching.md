## Goal

## Background

### Never concatenate paths with strings
`dir + '/' + file` breaks on Windows (`\`), doubles slashes, and mishandles `..`. Use `node:path`:

| Function | Example | Result |
|----------|---------|--------|
| `join(...parts)` | `join('a', '../b', 'c.txt')` | `b/c.txt` (normalised) |
| `resolve(...parts)` | `resolve('src', 'app.js')` | absolute path from `process.cwd()` |
| `dirname / basename / extname` | `extname('a/b.test.js')` | `.js` |
| `parse(p)` / `format(obj)` | `parse('/x/y.txt')` | `{ root, dir, base, name, ext }` |
| `relative(from, to)` | `relative('/a/b', '/a/c/d')` | `../c/d` |
| `sep`, `delimiter` | | `/` and `:` on POSIX |
| `isAbsolute(p)` | | `true` / `false` |

`resolve` vs `join`: `join` just glues and normalises; `resolve` always produces an **absolute** path and treats a later absolute segment as a new root.

### Paths relative to your module, not the cwd
`readFile('config.json')` is resolved against `process.cwd()` — wherever the user ran the command. To read a file next to your source, use `join(import.meta.dirname, 'config.json')` or `new URL('./config.json', import.meta.url)` (fs functions accept `URL` objects).

### Directory operations
- `mkdir(path, { recursive: true })` — creates parents; no error if it exists.
- `readdir(path, { withFileTypes: true })` — returns `Dirent`s so you don't need a `stat` per entry. Add `recursive: true` to walk the whole tree.
- `rm(path, { recursive: true, force: true })` — delete a tree (like `rm -rf`).
- `cp(src, dest, { recursive: true })` — copy a tree.
- `fs.glob('src/**/*.js')` — pattern matching (Node 22+; marked experimental on some versions).

### Watching files
`fs.watch` uses the OS's native notification API (inotify, FSEvents, ReadDirectoryChangesW). It's efficient but quirky:
- One save can fire **several** events (editors write temp files, then rename).
- Event types are only `'rename'` (created, deleted, or renamed) and `'change'`.
- `recursive: true` works on macOS and Windows, and on Linux since Node 20.
- The `filename` argument can occasionally be `null`.

Always **debounce** watch events and re-check the filesystem rather than trusting the event type. `fs.watchFile` polls with `stat` instead — slower and heavier, but useful on network filesystems.

### 3. Build a tree to work with

```js
// setup.js
import { mkdir, writeFile } from 'node:fs/promises';
import { join } from 'node:path';

const files = [
  'project/src/index.js', 'project/src/lib/math.js', 'project/src/lib/math.test.js',
  'project/docs/readme.md', 'project/node_modules/pkg/index.js', 'project/.env',
];
for (const f of files) {
  await mkdir(join(f, '..'), { recursive: true });
  await writeFile(f, `// ${f}\n`.repeat(10));
}
console.log('created', files.length, 'files');
```

### 4. Walk a directory tree

```js
// walk.js
import { readdir, stat } from 'node:fs/promises';
import { join } from 'node:path';

// 4a. Manual recursive generator — lets you skip directories
async function* walk(dir, { ignore = new Set() } = {}) {
  for (const entry of await readdir(dir, { withFileTypes: true })) {
    if (ignore.has(entry.name)) continue;
    const full = join(dir, entry.name);
    if (entry.isDirectory()) yield* walk(full, { ignore });
    else if (entry.isFile()) yield full;
  }
}

let total = 0;
for await (const file of walk('project', { ignore: new Set(['node_modules', '.git']) })) {
  const { size } = await stat(file);
  total += size;
  console.log(file.padEnd(40), size);
}
console.log('total bytes:', total);

// 4b. Built-in recursive readdir
const all = await readdir('project', { recursive: true });
console.log('recursive readdir:', all.length, 'entries (includes node_modules)');
```

### 5. Glob, copy, and delete

```js
// glob.js
import { glob, cp, rm } from 'node:fs/promises';

for await (const file of glob('project/src/**/*.test.js')) {
  console.log('test file:', file);
}

await cp('project/src', 'backup/src', { recursive: true });
console.log('copied src → backup/src');

await rm('backup', { recursive: true, force: true });
console.log('removed backup');
```

If `glob` is unavailable or warns on your Node version, note the warning; Task 4's walker is the portable fallback.

### 6. Watch with debouncing

```js
// watch.js
import { watch } from 'node:fs';
import { stat } from 'node:fs/promises';
import { join } from 'node:path';

const dir = 'project/src';
const pending = new Map();      // filename → timer

watch(dir, { recursive: true }, (eventType, filename) => {
  if (!filename) return;
  clearTimeout(pending.get(filename));
  pending.set(filename, setTimeout(async () => {
    pending.delete(filename);
    const full = join(dir, filename);
    try {
      const s = await stat(full);
      console.log(`[${new Date().toLocaleTimeString()}] changed: ${full} (${s.size} bytes)`);
    } catch (err) {
      if (err.code === 'ENOENT') console.log(`[${new Date().toLocaleTimeString()}] removed: ${full}`);
      else throw err;
    }
  }, 100));
});

console.log(`watching ${dir} — edit, create, or delete files`);
```

First remove the debounce (log directly in the watch callback) and save a file from your editor — count the events. Then restore it.

### 7. Async-iterator watcher with cancellation

```js
// watch-iter.js
import { watch } from 'node:fs/promises';

const ac = new AbortController();
setTimeout(() => ac.abort(), 15_000);

try {
  for await (const { eventType, filename } of watch('project', { recursive: true, signal: ac.signal })) {
    console.log(eventType, filename);
  }
} catch (err) {
  if (err.name !== 'AbortError') throw err;
  console.log('stopped watching');
}
```
