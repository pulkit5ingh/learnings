# A6.1 — Child Processes

**Phase:** 6 — Performance & Concurrency
**Topic:** `spawn`, `execFile`, `exec`, `fork`, stdio, IPC, exit codes, signals, timeouts, avoiding shell injection
**Type:** Assignment

---

## Goal
Run external programs and other Node scripts from Node safely, stream their output, communicate with them, and handle failures, timeouts, and cleanup.

## Background

### Four ways to start a process
| Function | Shell? | Output | Use for |
|----------|--------|--------|---------|
| `spawn(cmd, args, opts)` | No (by default) | Streams | Long-running processes, large output, anything interactive |
| `execFile(file, args, opts, cb)` | No | Buffered (callback/promise) | Short commands with small output |
| `exec(command, opts, cb)` | **Yes** | Buffered | Only when you need shell features (pipes, globs) on **trusted** input |
| `fork(modulePath, args, opts)` | No | Streams + **IPC channel** | Running another Node.js script and exchanging messages |

Each has a `…Sync` variant that blocks the event loop — fine in scripts, wrong in servers.

### Buffered vs streamed output
`exec`/`execFile` collect all output in memory and fail if it exceeds `maxBuffer` (1 MB by default). `spawn` gives you `child.stdout` and `child.stderr` as Readable streams, so output of any size can be processed as it arrives.

### stdio options
`stdio: 'pipe'` (default) gives you streams; `'inherit'` connects the child directly to your terminal; `'ignore'` discards. You can mix per stream: `['ignore', 'pipe', 'inherit']`. `fork` adds an `'ipc'` channel.

### Exit codes, signals, and errors
- `'error'` — the process **could not be started** (`ENOENT`: command not found) or couldn't be killed.
- `'exit'` / `'close'` — `(code, signal)`. `code` is the exit status; if the process was killed, `code` is `null` and `signal` is e.g. `'SIGTERM'`. `'close'` fires after all stdio streams have closed — prefer it when you read output.

Always handle `'error'` **and** check the exit code: a command that runs but fails exits non-zero and does **not** emit `'error'`.

### Timeouts and cancellation
Pass `timeout` (ms) and `killSignal`, or `signal: AbortSignal.timeout(ms)`, so a hung child doesn't hang your program. Children don't automatically die when the parent dies unless they're in the same process group receiving the signal — clean up explicitly on shutdown.

### Never build shell strings from input
`exec(\`git log ${branch}\`)` is command injection (A5.4). Use `spawn`/`execFile` with an argument array. If you must use a shell, pass user input via environment variables, never interpolation.

## Tasks

### 1. execFile with promises

```bash
mkdir a6-1-child && cd a6-1-child
npm init -y && npm pkg set type=module
git init -q && git commit -q --allow-empty -m "first" && git commit -q --allow-empty -m "second"
```

```js
// execfile.js
import { execFile } from 'node:child_process';
import { promisify } from 'node:util';

const run = promisify(execFile);

const { stdout } = await run('git', ['log', '--oneline', '-n', '5']);
console.log(stdout.trim().split('\n'));

try {
  await run('git', ['checkout', 'no-such-branch']);
} catch (err) {
  console.log('exit code:', err.code, '| stderr:', err.stderr.trim());   // runs, but exits non-zero
}

try {
  await run('definitely-not-a-command');
} catch (err) {
  console.log('spawn error:', err.code);    // ENOENT — never started
}
```

### 2. spawn and stream output

```js
// spawn.js
import { spawn } from 'node:child_process';
import { createInterface } from 'node:readline';

const child = spawn('ping', ['-c', '4', 'example.com']);    // Windows: ['-n', '4', ...]

for await (const line of createInterface({ input: child.stdout })) {
  console.log(`[ping] ${line}`);
}

const [code, signal] = await new Promise((resolve, reject) => {
  child.on('error', reject);
  child.on('close', (c, s) => resolve([c, s]));
});
console.log(`ping exited code=${code} signal=${signal}`);
```

### 3. A reusable `run` helper with timeout

```js
// run.js
import { spawn } from 'node:child_process';

export function run(cmd, args = [], { timeoutMs = 10_000, input, cwd, env } = {}) {
  return new Promise((resolve, reject) => {
    const child = spawn(cmd, args, { cwd, env, signal: AbortSignal.timeout(timeoutMs) });
    let stdout = '', stderr = '';
    child.stdout.setEncoding('utf8').on('data', (d) => (stdout += d));
    child.stderr.setEncoding('utf8').on('data', (d) => (stderr += d));
    child.on('error', (err) => reject(err.name === 'AbortError' ? new Error(`${cmd} timed out after ${timeoutMs}ms`) : err));
    child.on('close', (code, signal) => {
      if (code === 0) resolve({ stdout, stderr });
      else reject(Object.assign(new Error(`${cmd} exited with ${code ?? signal}: ${stderr.trim()}`), { code, signal, stdout, stderr }));
    });
    if (input !== undefined) child.stdin.end(input);
  });
}
```

```js
// use-run.js
import { run } from './run.js';

console.log((await run('sort', [], { input: 'banana\napple\ncherry\n' })).stdout);
try { await run('sleep', ['5'], { timeoutMs: 500 }); } catch (err) { console.log(err.message); }
try { await run('ls', ['/nope']); } catch (err) { console.log(err.message); }
```

### 4. Pipe processes together without a shell

```js
// pipe.js — equivalent of: cat package.json | grep -o '"' | wc -l   (count quote characters)
import { spawn } from 'node:child_process';
import { once } from 'node:events';

const cat = spawn('cat', ['package.json']);
const grep = spawn('grep', ['-o', '"']);
const wc = spawn('wc', ['-l'], { stdio: ['pipe', 'inherit', 'inherit'] });

cat.stdout.pipe(grep.stdin);
grep.stdout.pipe(wc.stdin);

await once(wc, 'close');
console.log('pipeline finished');
```

### 5. fork with IPC

```js
// worker-child.js
process.on('message', (msg) => {
  if (msg.type === 'fib') {
    const fib = (n) => (n < 2 ? n : fib(n - 1) + fib(n - 2));
    process.send({ type: 'result', id: msg.id, value: fib(msg.n) });
  }
  if (msg.type === 'exit') process.disconnect();      // closing IPC lets the child exit
});
process.send({ type: 'ready', pid: process.pid });
```

```js
// fork.js
import { fork } from 'node:child_process';
import { once } from 'node:events';

const child = fork(new URL('./worker-child.js', import.meta.url));
const [ready] = await once(child, 'message');
console.log('child ready', ready);

const pending = new Map();
child.on('message', (m) => { if (m.type === 'result') { pending.get(m.id)(m.value); pending.delete(m.id); } });
const fib = (n) => new Promise((resolve) => { const id = Math.random(); pending.set(id, resolve); child.send({ type: 'fib', id, n }); });

const ticker = setInterval(() => process.stdout.write('.'), 50);   // proves the parent stays responsive
console.log('\nfib(38) =', await fib(38));
clearInterval(ticker);

child.send({ type: 'exit' });
const [code] = await once(child, 'exit');
console.log('child exited', code);
```

### 6. Signals and cleanup

```js
// supervisor.js
import { spawn } from 'node:child_process';

const child = spawn(process.execPath, ['-e', `
  process.on('SIGTERM', () => { console.log('child: got SIGTERM, cleaning up'); setTimeout(() => process.exit(0), 300); });
  setInterval(() => console.log('child: working'), 500);
`], { stdio: 'inherit' });

child.on('exit', (code, signal) => console.log(`supervisor: child exited code=${code} signal=${signal}`));

setTimeout(() => {
  console.log('supervisor: sending SIGTERM');
  child.kill('SIGTERM');
  const force = setTimeout(() => child.kill('SIGKILL'), 2000);   // escalate if it ignores us
  child.once('exit', () => clearTimeout(force));
}, 1600);

process.on('SIGINT', () => { child.kill('SIGTERM'); });          // don't orphan the child on Ctrl+C
```
