## Background

### TCP: a reliable byte stream
`node:net` provides TCP. `net.createServer(socket => …)` accepts connections; `net.connect(port, host)` opens one. Each `net.Socket` is a **Duplex stream**: you read what the peer sends and write what you want to send. TCP guarantees bytes arrive **in order and without loss** — but it has **no concept of messages**.

### The framing problem
If a client writes `"hello"` and then `"world"`, the server might receive `"helloworld"` in one chunk, or `"hel"` and `"loworld"`. TCP delivers a stream, not packets you wrote. Every protocol on top of TCP must define message boundaries:

- **Delimiter-based** — messages end with `\n` (Redis inline commands, SMTP, many chat protocols).
- **Length-prefixed** — each message starts with its byte length, e.g. a 4-byte big-endian integer (many binary protocols, Postgres wire protocol).

HTTP itself uses both: headers end with `\r\n\r\n`, then `Content-Length` or chunked encoding frames the body.

### Socket lifecycle
Events: `'data'`, `'end'` (peer finished sending — half-close), `'close'` (fully closed), `'error'` (e.g. `ECONNRESET`, `ECONNREFUSED`), `'timeout'` (after `setTimeout(ms)` idle). Always handle `'error'` on every socket — an unhandled socket error crashes the server.

### UDP: messages without connections
`node:dgram` provides UDP. There are no connections and no streams: you `send()` individual **datagrams** to an address and receive them in `'message'` events. Each datagram arrives whole or not at all, but delivery and order are **not** guaranteed. UDP is used for DNS, metrics (StatsD), game state, video, and service discovery (broadcast/multicast), where low latency matters more than reliability.

```js
// echo-server.js
import { createServer } from 'node:net';

const server = createServer((socket) => {
  const who = `${socket.remoteAddress}:${socket.remotePort}`;
```

### 3. Delimiter framing: a line protocol key-value store

```js
// kv-server.js
import { createServer } from 'node:net';
import { createInterface } from 'node:readline';

const store = new Map();

function handle(line) {
  const [cmd, key, ...rest] = line.trim().split(' ');
  switch (cmd?.toUpperCase()) {
    case 'SET': if (!key) return 'ERR usage: SET key value'; store.set(key, rest.join(' ')); return 'OK';
    case 'GET': return store.has(key) ? `VALUE ${store.get(key)}` : 'NIL';
    case 'DEL': return store.delete(key) ? 'DELETED' : 'NIL';
    case 'KEYS': return `KEYS ${[...store.keys()].join(' ')}`;
    case 'QUIT': return null;
    default: return `ERR unknown command ${cmd}`;
  }
}

createServer((socket) => {
  socket.on('error', (err) => console.error(err.code));
  const lines = createInterface({ input: socket, crlfDelay: Infinity });   // readline frames on \n
  lines.on('line', (line) => {
    if (!line.trim()) return;
    const reply = handle(line);
    if (reply === null) return socket.end('BYE\n');
    socket.write(`${reply}\n`);
  });
}).listen(4001, () => console.log('kv store on :4001'));
```

```bash
printf 'SET name Ada Lovelace\nGET name\nKEYS\nDEL name\nGET name\nQUIT\n' | nc localhost 4001
```

### 4. Length-prefix framing for binary messages

```js
// framing.js
export function encodeFrame(obj) {
  const payload = Buffer.from(JSON.stringify(obj));
  const header = Buffer.alloc(4);
  header.writeUInt32BE(payload.length);
  return Buffer.concat([header, payload]);
}

// Returns a 'data' handler that calls onMessage once per complete frame
export function createDecoder(onMessage, { maxFrame = 1_000_000 } = {}) {
  let buffer = Buffer.alloc(0);
  return (chunk) => {
    buffer = Buffer.concat([buffer, chunk]);
    while (buffer.length >= 4) {
      const len = buffer.readUInt32BE(0);
      if (len > maxFrame) throw new Error(`frame too large: ${len}`);
      if (buffer.length < 4 + len) break;               // wait for more bytes
      onMessage(JSON.parse(buffer.subarray(4, 4 + len)));
      buffer = buffer.subarray(4 + len);
    }
  };
}
```

```js
// rpc-server.js
import { createServer } from 'node:net';
import { encodeFrame, createDecoder } from './framing.js';

const methods = {
  add: ({ a, b }) => a + b,
  upper: ({ s }) => s.toUpperCase(),
  time: () => new Date().toISOString(),
};

createServer((socket) => {
  socket.on('error', () => {});
  socket.on('data', createDecoder(({ id, method, params }) => {
    const fn = methods[method];
    socket.write(encodeFrame(fn ? { id, result: fn(params) } : { id, error: `unknown method ${method}` }));
  }));
}).listen(4002, () => console.log('rpc on :4002'));
```

```js
// rpc-client.js
import { connect } from 'node:net';
import { once } from 'node:events';
import { encodeFrame, createDecoder } from './framing.js';

const socket = connect(4002);
await once(socket, 'connect');

const pending = new Map();
let nextId = 1;
socket.on('data', createDecoder(({ id, result, error }) => {
  const p = pending.get(id);
  pending.delete(id);
  error ? p.reject(new Error(error)) : p.resolve(result);
}));

const call = (method, params) => new Promise((resolve, reject) => {
  const id = nextId++;
  pending.set(id, { resolve, reject });
  socket.write(encodeFrame({ id, method, params }));
});

// Fire many calls at once — frames may share or split chunks, the decoder copes
const results = await Promise.all([
  call('add', { a: 2, b: 3 }),
  call('upper', { s: 'framing works' }),
  call('time'),
  ...Array.from({ length: 100 }, (_, i) => call('add', { a: i, b: i })),
]);
console.log(results.slice(0, 3), '…', results.length, 'responses');
socket.end();
```

### 5. UDP: send and receive datagrams

```js
// udp-server.js
import { createSocket } from 'node:dgram';

const server = createSocket('udp4');
const counters = new Map();

server.on('message', (msg, rinfo) => {
  // StatsD-style metric: "name:value|c"
  const [name, rest] = msg.toString().split(':');
  const value = Number(rest?.split('|')[0] ?? 1);
  counters.set(name, (counters.get(name) ?? 0) + value);
  console.log(`from ${rinfo.address}:${rinfo.port} → ${name} = ${counters.get(name)}`);
});
server.on('error', (err) => { console.error(err); server.close(); });
server.bind(8125, () => console.log('udp metrics on :8125'));
```

```js
// udp-client.js
import { createSocket } from 'node:dgram';

const client = createSocket('udp4');
const metrics = ['page.views:1|c', 'page.views:1|c', 'signups:1|c', 'page.views:3|c'];
let sent = 0;
for (const m of metrics) {
  client.send(m, 8125, 'localhost', (err) => {
    if (err) console.error(err);
    if (++sent === metrics.length) client.close();
  });
}
```

Stop the UDP server and run the client again: no error — UDP doesn't know whether anyone received it.
