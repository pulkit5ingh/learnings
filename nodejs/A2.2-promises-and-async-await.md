## Background

### What a promise is
A promise is an object representing a value that will be available later. It is **pending**, then settles exactly once as **fulfilled** (with a value) or **rejected** (with a reason). `.then()` callbacks always run asynchronously as microtasks, even if the promise is already settled.

### async/await
An `async` function always returns a promise. `await` pauses the function until the awaited promise settles, then resumes with its value — or throws its rejection reason, so ordinary `try/catch/finally` works again.

### Sequential vs parallel
```js
const a = await getA();   // waits
const b = await getB();   // only starts after A finishes  → time = A + B

const [a, b] = await Promise.all([getA(), getB()]);  // both start now → time = max(A, B)
```
Accidental sequential awaits inside loops are one of the most common Node performance bugs.

### The combinators
| Combinator | Resolves when | Rejects when |
|------------|--------------|--------------|
| `Promise.all` | all fulfil (array of values) | **any** rejects (fail-fast) |
| `Promise.allSettled` | all settle (array of `{status, value|reason}`) | never |
| `Promise.race` | first one settles | first one rejects |
| `Promise.any` | first one fulfils | all reject (`AggregateError`) |

### Unbounded parallelism is a bug too
`Promise.all(files.map(read))` on 50,000 files opens 50,000 file handles at once → `EMFILE`. Process large collections with a **concurrency limit**: N workers pulling from a shared queue.

### Cancellation with AbortController
`AbortController` is the standard cancellation mechanism. You pass `controller.signal` to any API that accepts `{ signal }` — `fetch`, `fs.readFile`, `timers/promises.setTimeout`, `events.once`, `stream.pipeline` — and call `controller.abort()` to cancel. `AbortSignal.timeout(ms)` creates a signal that aborts automatically, and `AbortSignal.any([...])` combines signals.

### Unhandled rejections
A rejected promise that nobody handles triggers `unhandledRejection`, and **Node crashes by default** (since v15). Every promise must eventually be awaited or have a `.catch()`.

### 2. Sequential vs parallel timing

```js
// timing.js
import { setTimeout as sleep } from 'node:timers/promises';

const task = async (name, ms) => { await sleep(ms); return name; };

console.time('sequential');
for (const [n, ms] of [['a', 300], ['b', 300], ['c', 300]]) await task(n, ms);
console.timeEnd('sequential');               // ~900ms

console.time('parallel');
await Promise.all([task('a', 300), task('b', 300), task('c', 300)]);
console.timeEnd('parallel');                 // ~300ms
```

### 3. Combinators side by side

```js
// combinators.js
import { setTimeout as sleep } from 'node:timers/promises';

const ok = (v, ms) => sleep(ms).then(() => v);
const fail = (msg, ms) => sleep(ms).then(() => { throw new Error(msg); });

try {
  await Promise.all([ok('a', 100), fail('boom', 50), ok('c', 200)]);
} catch (err) {
  console.log('all rejected:', err.message);
}

console.log('allSettled:', await Promise.allSettled([ok('a', 100), fail('boom', 50)]));
console.log('race:', await Promise.race([ok('slow', 200), ok('fast', 50)]));
console.log('any:', await Promise.any([fail('x', 10), ok('first success', 100)]));

try {
  await Promise.any([fail('x', 10), fail('y', 20)]);
} catch (err) {
  console.log('any rejected:', err.constructor.name, err.errors.map(e => e.message));
}
```

### 4. A concurrency-limited map

```js
// pool.js
export async function mapLimit(items, limit, fn) {
  const results = new Array(items.length);
  let next = 0;

  async function worker() {
    while (next < items.length) {
      const i = next++;                 // safe: JS is single-threaded between awaits
      results[i] = await fn(items[i], i);
    }
  }

  const workers = Array.from({ length: Math.min(limit, items.length) }, worker);
  await Promise.all(workers);
  return results;
}
```

```js
// use-pool.js
import { setTimeout as sleep } from 'node:timers/promises';
import { mapLimit } from './pool.js';

let active = 0, peak = 0;
const ids = Array.from({ length: 20 }, (_, i) => i);

console.time('limited');
const out = await mapLimit(ids, 4, async (id) => {
  peak = Math.max(peak, ++active);
  await sleep(100);
  active--;
  return id * 2;
});
console.timeEnd('limited');              // ~500ms (20 items / 4 at a time × 100ms)
console.log('peak concurrency:', peak);  // 4
console.log(out.slice(0, 5));
```

### 5. Timeouts and cancellation

```js
// abort.js
import { setTimeout as sleep } from 'node:timers/promises';

// 5a. A timeout signal
try {
  await sleep(5000, undefined, { signal: AbortSignal.timeout(200) });
} catch (err) {
  console.log('5a:', err.name, err.cause?.name);   // AbortError TimeoutError
}

// 5b. Manual cancellation
const controller = new AbortController();
setTimeout(() => controller.abort(new Error('user cancelled')), 100);
try {
  await fetch('https://httpbin.org/delay/5', { signal: controller.signal });
} catch (err) {
  console.log('5b:', err.name, err.cause?.message ?? err.message);
}

// 5c. A generic withTimeout helper for APIs that don't accept a signal
export function withTimeout(promise, ms) {
  let timer;
  const timeout = new Promise((_, reject) => {
    timer = setTimeout(() => reject(new Error(`timed out after ${ms}ms`)), ms);
  });
  return Promise.race([promise, timeout]).finally(() => clearTimeout(timer));
}

try {
  await withTimeout(sleep(1000), 100);
} catch (err) {
  console.log('5c:', err.message);
}
```

### 6. Error handling patterns

```js
// errors.js
async function loadUser(id) {
  if (id < 0) throw new Error(`invalid id ${id}`);
  return { id };
}

// try/catch/finally
try {
  await loadUser(-1);
} catch (err) {
  console.log('caught:', err.message);
} finally {
  console.log('cleanup always runs');
}

// Forgetting await: the error escapes the try block
try {
  loadUser(-2);           // ← no await
} catch {
  console.log('never printed');
}

process.on('unhandledRejection', (reason) => {
  console.log('unhandledRejection:', reason.message);
});
```

Remove the `unhandledRejection` listener and run again — Node exits with code 1.
