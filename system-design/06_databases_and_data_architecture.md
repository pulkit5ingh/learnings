## 2. Database categories

| Category | Examples | Best for |
| --- | --- | --- |
| Relational databases | PostgreSQL, MySQL | Structured relationships, joins, transactions and complex queries |
| Key-value stores | Redis, DynamoDB key-value access patterns | Sessions, counters, cache entries and fast lookups |
| Document databases | MongoDB | Flexible documents, embedded structures and aggregate-oriented queries |
| Wide-column stores | Cassandra, HBase | Large-scale distributed workloads designed around access patterns |
| Graph databases | Neo4j | Relationship-heavy queries such as recommendations and social graphs |
